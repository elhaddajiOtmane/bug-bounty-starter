# /design-review — Design review

1. Open the page in the browser and screenshot desktop (1440px) and mobile (360px).
2. Use the `web-design-guidelines` skill as the audit checklist.
3. Judge, in this order: hierarchy (what do you see first, second, third?), typography (scale, pairing, line-height), color (one system, contrast 4.5:1), spacing rhythm, motion (does every animation have a job?), mobile composition.
4. Name the generic-AI tells if present: default gradients, identical cards, stock icons, everything fading in at once.
5. Output: top 5 fixes ranked by impact, each with the exact change (values, not vibes). Then apply them if the user asked for fixes, and re-screenshot.
