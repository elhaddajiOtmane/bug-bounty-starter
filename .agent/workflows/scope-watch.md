# /scope-watch — Daily fresh-surface check (15 minutes)

Run this before any hunting session. Output: an updated "fresh list" in your tracker.

1. **New launches (5 min).** Check the program directories of your platforms for programs launched in the last 7 days. Shortlist by `bug-bounty-business` rules: wildcard scope, pays for web classes, responsive triage. Note launch date — under 72 hours = rush candidate.
2. **Scope changes (5 min).** For your 3–5 home programs: re-read the scope section; diff against your saved copy. Any new asset, domain, or feature → top of the fresh list, marked with today's date.
3. **New surface diff (5 min).** Re-run subdomain enumeration for your top program (`hunt-subdomain`) and diff against last week's list. New hosts go on the fresh list even if the scope page didn't change — companies ship first and document later (still verify the host is in scope before testing it).
4. Decide today's hunt from the fresh list ONLY. If the list is empty, deep-hunt your home program's newest feature — never a random famous program's login page.
